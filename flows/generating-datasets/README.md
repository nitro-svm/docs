# Generating Datasets

Replaying historical state makes it possible to measure things that aren't visible onchain: how deep each pool actually was at a given size, how a router quoted that liquidity, when two venues' quotes crossed, and what a venue would have filled on swaps it didn't win. These measurements are published as Parquet datasets for offline analysis.

* [Prebuilt datasets](prebuilt-datasets.md) are ready to download.
* [Custom datasets](custom-datasets.md) are measured on request, for the slot range and markets you choose.

Both are read with the credentials `sim datasets credentials` prints.
